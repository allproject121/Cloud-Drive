4️⃣ Live System Pipeline (How It Works)
WinFsp / rclone VFS

💽 Feature 1: Virtual Cloud SSD Mount & Multi-Account Pooling

Windows Explorer file read requests are intercepted by the user-mode filesystem driver and streamed dynamically from pooled Google accounts with zero upfront download.

⚡ Execution Steps:
01. WinFsp Driver Intercept: Catches Windows Explorer IRP_MJ_READ non-blocking I/O calls.
02. Chunk Slicer: rclone VFS router checks local sparse cache on C:\; slices missing regions into 4MB blocks.
03. Parallel HTTP 206 Range: Requests sent directly to Google Drive API over TLS 1.3 multiplexed stream.
04. Zero-Copy Memory Fill: Injects received byte buffer directly into calling process RAM without blue-screen risk.
Underlying APIs & Protocols:
• Driver: WinFsp User-Mode File System (Z: All, Y: Individual)
• Cache: Sparse NTFS File (FSCTL_SET_SPARSE)
• Network: HTTP/2 Multiplexing + TLS 1.3 AES-GCM
